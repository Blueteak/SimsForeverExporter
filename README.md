# SimsForever Exporter

Exports WoW Forever character data for [SimsForever](https://simsforever.com).

Run `/simf`, `/sfexport`, or `/simsforever` to open the export. Press Ctrl+C to copy and close the window, then paste at [SimsForever](https://simsforever.com/).

Exports equipped gear plus equippable gear in carried bags. 

## Some Notes
- Bank contents are included if the bank window is open. 
- Current resources, spell costs, and pet spell details are added for diagnostics. 
- SimsForever selects starting resources and uses internal spell and pet data. 
- Unreadable optional fields are omitted without warnings.
- CurseForge packages version tags automatically.
